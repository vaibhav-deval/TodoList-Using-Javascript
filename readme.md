# 🗂️ Kanban Board – Vanilla JavaScript

A simple and interactive **Kanban Board** built using **HTML, CSS, and Vanilla JavaScript**.  
This project allows users to manage tasks across different stages using **drag and drop**, with data persistence via **localStorage**.

---

## ✨ Features

- ➕ Add new tasks with title and description
- 🗑️ Delete tasks instantly
- 🖱️ Drag & Drop tasks between columns
- 📊 Real-time task count per column
- 💾 Persistent data using `localStorage`
- 🧠 Clean, readable, and well-commented code

---

## 🧱 Columns

- **To Do**
- **In Progress**
- **Done**

Tasks can be freely moved between these columns.

---

## 🛠️ Tech Stack

- **HTML5** – Structure & semantics
- **CSS3** – Layout & styling
- **JavaScript (Vanilla)** – Logic & interactivity
- **LocalStorage API** – Data persistence

🚀 How It Works

Tasks are created via a modal form.

Each task is draggable across columns.

Task counts update dynamically.

All tasks are stored column-wise in localStorage.

On page reload, tasks are restored automatically.
